配置步骤
  1. 先点击下方按钮生成上传凭证，再下载并添加两个快捷指令。
  2. 安装时填写服务器地址和上传凭证。手机需能访问该地址；公网使用 HTTPS，地址末尾不带斜杠。
  3. 首次运行允许网络、照片及通知权限。照片权限受限时，只能找到已授权的照片。
  4. 运行照片上传时保持快捷指令在前台；网络失败后可重新分享，已成功上传的相同照片会自动跳过。

凭证仅用于导入，不提供数据读取和删除权限。替换、撤销或更改系统密码后，旧凭证失效。请勿分享已填好凭证的快捷指令。

照片转换为最长边 720 像素的 JPEG；Live Photo 只上传静态图，不上传视频。按照片拍摄时间自动匹配记录及轨迹点位置。通知进度取决于 iOS 通知权限。

没有可安装文件时：在 iPhone 上手动创建

未签名源文件不能直接在 iPhone 安装。可在「快捷指令」中新建，分别创建以下两个快捷指令：

快捷指令一：Hiking · 上传 GPX

  1. 开启「在共享表单中显示」，接收「文件」。
  2. 添加两个「文本」操作，填写服务器地址及上传凭证，分别设为变量「服务器地址」「上传凭证」。
  3. 判断输入：若快捷指令输入项目数为 1 则设为「GPX文件」，否则添加「选取文件」操作选取文件设为「GPX文件」。
  4. 添加「列表」操作，包含「路线」和「记录」；添加「从列表中选取」操作提示选择上传类型。
  5. 若所选项为「路线」，设「类型」为 route；否则设「类型」为 record。
  6. 先「获取 URL 内容」：URL 为「服务器地址」加 /api/shortcut/gpx/preview?kind= 加「类型」，POST，请求体选「文件」，文件选「GPX文件」。请求头 Authorization: Bearer 上传凭证、X-Hiking-Kind: 类型。检查响应中的 error，若有则显示并停止；将响应 name 设为「当前名称」。此步只预览，不保存。
  7. 添加「从菜单中选取」，提示「当前读取的名称：当前名称，是否重命名？」，选项为「保留原名」「重命名」。选择重命名时「询问输入」新名称（1～160 字符，默认填当前名称），为空则停止；对新名称「URL 编码」，将 &name= 加编码结果作为「名称参数」。保留原名时「名称参数」为空。
  8. 再「获取 URL 内容」：URL 为「服务器地址」加 /api/shortcut/gpx?kind= 加「类型」加「名称参数」，POST，请求体及请求头同上。保存为记录时，记录和关联路线使用同一新名称。
  9. 检查响应中的 error，若有则显示并停止；成功则显示导入完成提示。

快捷指令二：Hiking · 批量上传照片

  1. 开启「在共享表单中显示」，接收「图像」。
  2. 添加两个「文本」操作，填写服务器地址及上传凭证，分别设为变量「服务器地址」「上传凭证」。
  3. 判断输入：若快捷指令输入项目数大于 0 则设为「待上传照片」，否则添加「选取照片」操作（开启多选）设为「待上传照片」。
  4. 「重复每一项」待上传照片：获取照片拍摄日期，格式化为 yyyy-MM-dd'T'HH:mm:ss.SSSXXX；调整图像大小最长边为 720 并转换为 JPEG。
  5. 在循环内「获取 URL 内容」：URL 为「服务器地址」加 /api/shortcut/photos，POST，请求体为转换后的 JPEG。请求头包含 Authorization: Bearer 上传凭证、X-Photo-Taken-At: 拍摄时间、Content-Type: image/jpeg。服务端将自动根据拍摄时间关联到对应徒步记录。
  6. 检查响应 error，发送进度通知。全部完成后显示完成提示。
